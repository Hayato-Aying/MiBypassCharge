MiBypassCharge — 旁路供电守护 (K70)
版本: v1.8.0-fork.1（基于上游 v1.8.0）

插电后充到「充到多少停」就停充，手机改由适配器直供（电池 0W），
掉到「用到多少才充」再恢复充电。停充走小米官方 smart_chg 位，
与安全中心「导航断充保护」同款，驱动自保持，拔插不丢。

开关层级：
  旁路供电      —— 总开关，关掉就是完全正常充电
  ├ 按阈值自动  —— 充到「充到多少停」就停充，掉到「用到多少才充」再补
  └ 立即旁充    —— 当场停充不补电，临时叠在按阈值自动之上

点法（总开关已开启）：
  · 按阈值自动：点一下开，再点一下关（关 = 正常充电）。
  · 没到停止值时点「立即旁充」= 当场停充；
    之后点「恢复正常」= 退回按阈值自动继续跑，不是正常充电。
  · 已经充到停止值（此时本来就已停充，等价于旁充中）点「恢复正常」
    = 立即旁充和按阈值自动两个都关掉，之后一直正常充，
      充满也不会自己把按阈值自动开回来。

KernelSU 模块，纯脚本 + WebUI，不安装任何 App。
适配 Redmi K70（vermeer / HyperOS 2 / Android 15）；其他机型未测试。

开源地址: https://github.com/ChangXYZ-CPU/MiBypassCharge
使用说明 / 更新日志 / 免责声明见仓库 README.md 与 DISCLAIMER.md。

修改系统充电行为有风险，请自行承担。安装前请备份数据。

控制中心磁贴（可选）:
  模块目录 webroot/MiBypassChargeTile.apk 是一个 17KB 的无界面伴生 App，
  只有一个 TileService，不占后台、不常驻。在 WebUI 点「安装」后，
  进控制中心 → 编辑 → 把「旁路供电」拖出来。
  磁贴主行直接显示当前结论：旁路充电开启 / 旁路充电关闭；
  副标题补充来源（立即旁充 / 阈值 80% 已停 / 正常充电 / 按阈值自动）。
  点一下 = 立即旁充，再点一下 = 恢复正常充电
  （等价于 bg-ctl.sh flip on / flip cancel）。
  阈值自动停在设定值时，磁贴也会显示「旁路充电开启」，和 App 里按钮同步。
  首次点击会弹一次 root 授权（KernelSU per-app 持久，之后不再弹）。
